#Rechnungen_automatisch_erstellen
Programm soll zuerst gescannte hangeschriebene PDFs einlesen
Dann diese in in Excel übertragen
Dann mit einer anderen Preistabelle in Excel (welcher Arbeitsschritt kostet was) die einzelnen Positionen abgleichen
Dann Rechnungen in PDF Format erstellen

Hierfür soll zusätzlich eine GUI entwickelt werden mit Eingabe Buttons für die PDFs zu einlesen und eine Rechnungserstellungsfunktion
